# Capstone Projects

Integrative projects that combine the core path and the tracks.

Curriculum and rationale: [`EDUCATION_STRATEGY.md`](../../doc/examples/EDUCATION_STRATEGY.md).

Delivery: E8.

| ID | Example | Concepts | Status |
|----|---------|----------|--------|
| P-01 | Calculator (RPN, BCD or fixed point) | L1–L3, S-01 | done |
| P-02 | Snake / Pong (graphics, keyboard, timer IRQ, sound) | S-03..S-10, O-13 | done |
| P-03 | Mini monitor/debugger (memory dump, edit, go; TRAP-based) | L3, S-08, S-11 | done |
| P-04 | Forth interpreter in assembly | L2–L3, O | done |
| P-05 | Preemptive mini-kernel (tasks, context switch on timer IRQ, user/supervisor, protected memory) | S-08..S-12, C-09 | done |
| P-06 | C++ game framework on libeasy68k, with hand-optimised asm hot paths | Track C, Track O | done |
| P-07 | Demo effect (plasma/rotozoom in fixed point within a cycle budget) | O-07, O-08, O-13 | done |

Directory names follow `<ID>-<name>`, e.g. `L2-06-stack-frames`.
